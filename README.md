# DPG Engenharia Mecânica

Site institucional estático, responsivo e sem dependência de build. O redesign adota linguagem editorial cinematográfica em grafite, branco e azul técnico, mantendo a identidade e os dados profissionais exibidos.

## Execução e publicação

Não há etapa de compilação nem instalação de pacotes. Abra `index.html` diretamente em um navegador ou sirva a pasta com qualquer servidor HTTP estático. Links, formulário e rotas são arquivos HTML/CSS/JS comuns.

Publicação configurada para GitHub Pages em `https://muitozika12.github.io/site-consultoria/` (Settings → Pages → Deploy from a branch → `main` → `/(root)`). Os links canônicos e o sitemap refletem esse endereço. Para outra URL de publicação, atualize os canônicos, URLs Open Graph e `sitemap.xml`.

## Estrutura

- `index.html`: página institucional, serviços, clientes, responsável técnico, contato e chamada ao caderno.
- `styles.css`: sistema visual responsivo compartilhado, menu mobile e regras de movimento reduzido.
- `script.js`: navegação mobile, ano do rodapé e preparação da mensagem para WhatsApp.
- `blog/index.html`: índice navegável do caderno técnico.
- `blog/artigos/*.html`: três artigos educativos independentes, cada qual com metadados, canônico e links de retorno.
- `sitemap.xml`, `robots.txt`: descoberta das páginas estáticas por mecanismos de busca.
- `logo.svg`, `favicon.svg`: marca e ícone existentes.
